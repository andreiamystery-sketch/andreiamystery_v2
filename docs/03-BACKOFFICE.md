# 03 - Backoffice

Rotas:

- `/admin/login`
- `/admin/produtos`
- `/admin/encomendas`

O admin usa Supabase Auth e validação server-side via `requireAdmin`.

## Encomendas

Inclui dashboard, filtros, CSV, drawer acessível, WhatsApp, copiar resumo, impressão, reenvio de email, alteração de estado logístico, estado de pagamento, notas internas e histórico.
