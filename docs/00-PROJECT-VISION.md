# 00 - Project Vision

Andrea's Mystery é uma loja online feminina, elegante e premium. A experiência deve ser limpa, direta e sofisticada: foco nas peças, confiança no checkout e backoffice simples para gestão diária.

Objetivos da v1.0:

- vender bijuteria premium com carrinho e checkout funcional;
- permitir gestão de produtos e encomendas via admin;
- guardar encomendas com dados de envio, pagamento e consentimento;
- manter base preparada para internacionalização e integrações futuras.
